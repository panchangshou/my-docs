# API 参考

以下接口仅用于文档展示，不提供真实服务。

## 查询文档列表

- 请求方法：GET
- 请求路径：/api/docs
- 功能：返回文档条目列表。

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"}
  ]
}
```

## 查询文档详情

- 请求方法：GET
- 请求路径：/api/docs/{id}
- 功能：根据文档编号返回单条文档。

### 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | 路径 | integer | 是 | 文档编号 |

### 返回示例

```json
{
  "id": 1,
  "title": "使用指南",
  "content": "修改 docs 目录中的 Markdown 文件。"
}
```

## 编写说明

这部分内容是我为练习接口文档写法而整理的。即使当前没有真实后端，也应当把请求方法、路径、参数和返回结构写清楚，让读者不依赖源码就能理解接口行为。表格用来描述参数，JSON 代码块用来展示返回示例，两者配合比大段文字更直观。
