## 实践体会

这次实践让我把“写文档”和“发布网站”真正连成了一条完整的链路。以前文档只是仓库里的 Markdown 文件，想看就必须先克隆仓库；现在 MkDocs 会把 docs 目录渲染成带导航的网页，GitHub Actions 又在每次推送到 main 后自动构建并发布到 GitHub Pages，读者打开网址就能阅读。

真正动手时我才发现，容易出错的往往不是命令本身，而是细节：mkdocs.yml 里的 nav 路径必须相对于 docs 目录，YAML 只能用空格缩进，部署工作流还需要写入权限。把这些问题和解决过程记录下来，是我这次最大的收获。

